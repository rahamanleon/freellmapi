Using the API

  • Base URL: /v1 on this host (OpenAI-compatible)
  • Auth: Authorization: Bearer <your unified API key> — the same key serves every /v1 route
  • Chat: POST /v1/chat/completions
  • Models: GET /v1/models, or send "model": "auto" and let the router pick
  • Web search: POST /v1/search, engines listed by GET /v1/search/engines
